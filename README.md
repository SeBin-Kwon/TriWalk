# 🏞️ 트리워크 - Triwalk

> 산책한 경로, 사진, 기록을 티켓처럼 모아두는 나만의 산책 여행 앱

TriWalk는 산책을 작은 여행으로 바꿔주어 즐길 수 있도록 동기부여해 주는 모바일 앱입니다. 실시간 위치 추적, 산책 경로 시각화, 걸음 수 측정, 그리고 다양한 날씨 정보를 제공하여 사용자들이 더 건강한 라이프스타일을 가질 수 있도록 돕습니다.

**집중 개발 기간:** 2025.03.28 ~ 2025.04.06

**유지 보수 기간:** 2025.04.07 ~ 2025.04.20

**인원:** 1명

**최소 버전:** iOS 15.0 이상

## 🛠️ 기술 스택

- **Architecture:** MVVM, Input-Output, Repository,  DI/DIP
- **Framework:** UIKit, Combine, CoreLocation,  CoreMotion, MapKit, PhotosUI
- **Library:** Alamofire, SnapKit, Realm
- **API:** OpenWeatherMap API,  한국환경공단 에어코리아 API

## 🌳 주요 기능

**실시간 산책 경로 기록**

- 지도로 실시간 경로를 확인하며 산책을 즐길 수 있어요.  

- 산책이 끝나면, 오늘의 여정을 티켓으로 저장해 드려요.

**산책과 함께 사진 기록**

- 산책 중 찍은 사진을 함께 저장할 수 있어요.

- 어디서 찍었는지 지도에 위치도 표시돼요.

**걸음 수, 이동 거리 자동 측정**  

- 걸음 수, 이동 거리, 소모 칼로리를 자동으로 기록해요.  

- 데이터는 티켓에 요약되어 저장됩니다.

**산책 출발지 및 도착지 설정**

- 출발지는 현재 위치를 기준으로 자동 설정돼요.

- 주소 검색이나 지도를 꾹 눌러 도착지를 직접 지정할 수 있어요.

**날씨, 미세먼지 정보**

- 산책 전, 현재 날씨와 미세먼지 등급을 확인하세요.

- 오늘 걷기에 좋은 날인지 바로 확인할 수 있어요.

**최근 산책 기록 확인**

- 최근 산책 데이터가 홈 화면에 티켓 형태로 표시돼요.  

- 거리, 시간, 칼로리까지 간단한 요약 정보로 확인할 수 있어요.

**산책 캘린더**

- 산책한 날짜가 캘린더에 표시돼요.

- 날짜별로 모든 산책 기록이 작은 티켓으로 정리돼요.

**상세 산책 기록**

- 해당 날짜의 날씨, 온도, 산책 경로까지 모두 확인 가능해요.

- 산책 중 찍은 사진도 함께 볼 수 있어요.

**산책 여행 리포트**

- 걸었던 모든 여정을 지도에서 한 눈에 볼 수 있어요.
-  나의 산책 최고 기록도 함께 확인해보세요.



## ⭐️ 기술 포인트

**경로 시각화 렌더링 시스템**

- MKMapView와 커스텀 오버레이를 활용해 경로 좌표별 시간 경과에 따른 투명도를 기반으로 한 경로 그라데이션 효과와 사진 위치의 실시간 렌더링을 구현했습니다.

**센서 기반 활동 추적 알고리즘**

- CoreMotion과 CoreLocation 데이터를 융합한 센서 기반 위치·활동 추적 알고리즘을 구축했습니다. 실시간 분석 및 필터링을 통해 백그라운드 상태에서도 걸음 수, 이동 거리, 칼로리 소모량을 높은 정밀도로 자동 측정할 수 있도록 했습니다.

**Combine 기반 단방향 데이터 흐름 아키텍처 설계**

- Combine 프레임워크의 Publisher/Subscriber 패턴과 커스텀 오퍼레이터를 활용하여, 단방향 데이터 흐름 기반으로 UI 상태와 비즈니스 로직을 효율적으로 연결했습니다.
